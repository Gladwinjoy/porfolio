Skills

HTML (HyperText Markup Language) is the standard language used to create and structure webpages. It uses tags to define elements such as text, headings, images, links, videos, and more. HTML is not a programming language but a markup language that tells the browser how to display content.

(Cascading Style Sheets) is a stylesheet language used to describe the presentation of HTML documents. It controls how web pages look by defining styles such as colors, fonts, margins, spacing, layouts, and responsiveness. With CSS, developers can separate content (HTML) from design, making websites easier to style

JavaScript is a high-level, lightweight, and versatile programming language mainly used to make web pages interactive and dynamic. While HTML structures the content and CSS styles it, JavaScript adds behavior—such as form validation, animations, interactive buttons, dynamic content updates, and more.

MongoDB is a popular NoSQL database that stores data in a flexible, JSON-like format called documents (instead of tables and rows like traditional SQL databases). It is designed for scalability, high performance, and easy handling of large amounts of unstructured or semi-structured data. MongoDB is widely used in modern web applications, especially with the MERN stack (MongoDB, Express.js, React.js, Node.js).

React is a popular JavaScript library developed by Facebook for building fast and interactive user interfaces, especially for single-page applications. It uses a component-based architecture, where UIs are broken into reusable pieces, and a virtual DOM to efficiently update only the parts of a webpage that change, making apps faster and smoother.

Node.js is an open-source, cross-platform runtime environment that allows you to run JavaScript code outside the browser. It is built on Google’s V8 JavaScript engine and is mainly used for building fast, scalable, and server-side applications. Node.js uses an event-driven, non-blocking I/O model, making it ideal for real-time applications like chat apps, APIs, and streaming services.

Express.js is a lightweight and fast web application framework for Node.js. It simplifies building web servers and APIs by providing easy-to-use methods for handling routes, requests, and responses. Express.js is widely used in the MERN stack to connect the frontend (React) with the backend and database (MongoDB).
